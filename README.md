# 내역서 물량산출 자동화 웹앱

내역서 엑셀(.xlsx)을 업로드하면 공종별 집계와 금액(수량 x 단가) 오류를 자동 검토하고, 결과 리포트를 엑셀로 내려받을 수 있는 Streamlit 웹앱입니다.

## 실행 방법
```
pip install -r requirements.txt
streamlit run app.py
```

## 설정
`app.py` 상단의 `COLUMN_MAP`을 실제 내역서 컬럼명에 맞게 수정하세요.

## 로드맵
1. 내역서 물량산출/오류 검토 (현재)
2. 표준품셈 단가 자동 매칭
3. 도면(DXF)-내역서 수량 대조
4. 태양광/ESS 인허가 자동화
