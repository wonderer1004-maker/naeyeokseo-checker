# 토목 내역서 검토 · 부지 개략공사비 웹앱

## 현장사진과 도면 출력

- 현장/드론 JPG·PNG·WebP 이미지 최대 8장(장당 10MB)을 첨부하고 촬영 위치·방향·검토 메모를 기록합니다. 기기에서 최대 1600px JPEG로 압축하며 원본·EXIF는 별도로 보관해야 합니다. 서버로 사진을 전송하지 않습니다.
- `사진 포함 프로젝트 저장`으로 입력 조건·현장명·주소·사진·메모를 JSON 파일에 보관하고 다시 불러올 수 있습니다. API 키는 저장하지 않습니다. 프로젝트 파일에는 현장정보와 사진이 포함되므로 공유 범위를 확인하세요.
- 산출 후 `A3 도면·현장사진 PDF 다운로드`를 누르면 배치도, 수량·공사비 내역, 계산 조건, 사진별 메모를 A3 가로 PDF로 바로 받습니다. 한글 호환성을 위해 PDF는 래스터 이미지 형식이며 CAD 편집용 벡터는 DXF/DWG를 사용합니다.
- 사진은 검토 증빙입니다. 사진 업로드만으로 필지경계·높이·토공량을 자동 복원하거나 배치도에 정합하지 않습니다. 측량 성과·정사영상·DEM/GCP 연계는 후속 개발 범위입니다.

### 실제 DWG 출력 (로컬 CAD 서버)

GitHub Pages에는 서버 프로그램이 없어 사진/PDF/DXF/프로젝트 저장은 가능하지만 DWG 직접 변환은 실행할 수 없습니다. 아래 로컬 앱에서 실제 DWG를 출력하거나 DXF를 CAD에서 열어 DWG로 저장하세요. `.dxf` 확장자를 `.dwg`로 변경하는 방식이 아닙니다.

1. Node.js와 [GNU LibreDWG 공식 배포본](https://github.com/LibreDWG/libredwg/releases/tag/0.14)을 준비합니다. Windows 64비트 zip의 모든 파일을 `.tools/libredwg/`에 풉니다. 실행파일과 함께 DLL도 필요합니다. 바이너리는 저장소에 포함하지 않습니다.
2. 작업 폴더에서 `node cad-server.cjs`를 실행합니다.
3. `http://127.0.0.1:8787/jibun-estimate.html`에서 산출 후 DWG 버튼을 누릅니다. 다른 설치 위치는 `DXF2DWG_PATH` 환경변수로 dxf2dwg 실행파일의 절대경로를 지정하세요.

로컬 서버는 127.0.0.1에만 바인딩하며 다른 출처 요청을 차단합니다. 변환 요청은 배치 도형만 포함하고 사진은 포함하지 않습니다. 임시 DXF/DWG는 변환 종료 시 정리합니다. 결과는 AutoCAD 2000(AC1015), 단위 m, x=동/y=북의 지역 좌표이며 `PARCEL`, `USABLE`, `SOLAR_MODULE`, `NOTES` 레이어를 제공합니다. DWG에 래스터 사진은 삽입하지 않고 PDF에 첨부합니다. 파일은 실제 측량·허가 도면이 아닌 개념 배치도입니다.

공개 웹사이트의 원클릭 DWG 출력에는 별도 변환 서비스와 인증·이용한도 연동이 필요합니다. 현재 로컬 전용 서버를 인터넷에 그대로 공개하지 마세요.

검증: `npm test`. 변환기 설치 시 DWG 생성 후 재읽기와 도형 수를 검사합니다. 미설치 시 해당 검증은 SKIP으로 표시합니다. Linux에서는 `DWGREAD_PATH`로 재읽기 실행파일도 지정하세요. PDF 통합 검증은 `npm install` 후 `npm run test:report`로 실행하며 `output/pdf/`에 합성 현장 이미지로 만든 샘플을 생성합니다. 운영 앱과 CAD 서버는 npm 의존성 설치 없이 실행됩니다.

GitHub Pages용 정적 웹앱은 `docs/`, Netlify용 동일 사본은 `netlify-site/`에 있습니다.

- 내역서 XLSX 검토: 수량×단가 오류, 숫자 입력 검증, 공종·단위별 집계, 결과 XLSX 다운로드
- 개략공사비: 부지 면적·경사도·가용비율·토공 평균깊이·옹벽 면적 및 편집 단가 입력
- 직접공사비·예비비·부가세 구분, 입력 조건·가정이 포함된 XLSX
- 정사각형 면적 가정의 개념 배치도 SVG / DXF(m 단위) 다운로드
- 인쇄 대화상자를 통한 PDF 저장
- VWorld 좌표 조회(베타): 키를 현재 화면에서만 사용하고 장기 저장하지 않음. API 허용 도메인 설정 필요.

## 계산 가정과 현재 범위
기본 단가는 검증된 시세나 공식 표준품셈이 아닙니다. 용도지역은 참고 기록만 하며 면적 가중치나 허가 판정에 사용하지 않습니다.
설치용량 = 배치도에 들어간 실제 모듈 수 × 모듈 정격출력 / 1000. 가용 수평면적을 기준으로 배치하며 경사도·용도지역에 임의 면적 감소 계수를 적용하지 않습니다.
토공량 = 수평면적 × 사용자 입력 평균 수직 두께. 토공비 포함/별도를 선택하며 별도 산정 시 부지조성 단가의 포함분을 제외해야 합니다.
옹벽은 사용자 입력 전면 면적에 단가를 적용합니다. 예비비는 직접공사비에, 부가세 10% 가정은 직접공사비+예비비에 적용합니다.
토지매입·계통연계 추가공사·설계/인허가비·금융비용은 제외됩니다.

지번만으로 필지 경계·용도지역·1:1000 지형도·DEM을 자동 분석하는 기능은 아직 미연동입니다.
출력 배치도는 실제 경계를 사용하지 않는 개념 도식이며 실시설계·허가 도면이 아닙니다.
엑셀 입출력은 외부 CDN의 SheetJS를 사용하므로 네트워크가 필요합니다. 보고서의 검토 오류는 표와 오류여부 열로 표시됩니다.

## 방향·계절 태양 조건 반영
- SVG와 DXF 좌표는 x=동, y=북(m). SVG 위쪽은 진북. 기본 모듈 정면 방위각 180°(남), 행은 동서 방향.
- 위도 20~50°N, 경사각 0~60°, 정면 방위각 90~270°, 모듈 크기·출력·통로·동일 행 모듈 간격을 입력.
- 춘추분 적위 0°, 하지 +23.44°, 동지 -23.44°를 사용하는 근사 태양 기하.
- 남중고도 = 90° − |위도 − 적위|. 낮 길이는 굴절·지평선 음영을 제외한 이론값.
- 높이차 H=L sin(경사각), 수평폭 B=L cos(경사각).
- 태양 위치 벡터에서 모듈 정면 방향 수평 성분/수직 성분으로 행 방향 그림자 투영을 계산. 동지 태양시 09~15시를 3분 간격으로 검토하거나 정오만 선택.
- 행간 순 간격 = max(검토시간 최대 H×그림자투영비, 최소 통로). 행 피치 = B + 순 간격. 정남향 정오의 경우 순 그림자 간격 = H/tan(동지 남중고도).
- 회전한 모든 모듈 꼭짓점이 가정한 가용 정사각형 경계 안에 들어가는 경우만 배치. 자동 최적화 또는 실제 필지 맞춤은 아님.
- 실제 부지 경사 방향·장애물·단차·음영 전기손실은 미반영. 3분 표본의 기하 간격은 연중 무음영 보장이 아님.
- 계절별 모듈 면(POA) 일사량(kWh/㎡/일)을 선택 입력. 빈 값을 날씨 데이터처럼 추정하지 않음. GHI를 그대로 넣지 말 것.
- 계절 발전량 가정 = kW × 평균 POA × 계절 일수 × PR. 평년 일수 92/92/91/90일. 남중 입사계수는 순간 직달 기하 지표이며 POA에 다시 곱하지 않음.
- XLSX의 계절별태양조건 시트에 고도·낮길이·입사계수·입력 일사량·발전량 가정이 포함됨.

참고: [NOAA 태양 계산 설명](https://gml.noaa.gov/grad/solcalc/calcdetails.html), [NREL SAM 음영 및 배치](https://samrepo.nlr.gov/help/pv_shading.html). 이 구현은 근사 기하 계산으로 NOAA/SAM 전체 모델의 구현이 아닙니다.

## 면적·내역서 검증과 그래픽 개선 (v1.2)

- θ=atan(경사율/100), 사면적=수평면적/cosθ. 수평면적·사면적과 %·°를 구분하고 평균 경사의 단일 평면으로 근사합니다. 실제 굴곡/DEM 표면적은 아닙니다. 경사 단위 참고: https://www.usgs.gov/educational-resources/determine-percent-slope-and-angle-slope
- 15% 초과 일괄 0.7 계수와 용도지역 면적 가중치를 제거했습니다. 배치 수량은 가용 수평면적을 기준으로 계산합니다. 경사 방향에 따른 음영은 미반영이며 평탄 설치면을 가정합니다.
- 부지조성비의 수평/사면 수량 기준과 토공비 포함/별도 방식을 선택합니다. 토공량=수평면적×수직 두께이며 절토·성토·팽창/다짐·토질/운반비는 별도 검토해야 합니다. 별도 산정은 양의 단가를 요구하고 부지조성 단가의 토공 포함분을 사용자가 제외해야 합니다.
- 수량 소수 3자리, 단가 소수 2자리 반올림 후 표시된 값으로 행 금액 원단위 반올림. 십진수 곱셈은 BigInt 유리수로 처리합니다. 행 금액 합계를 기준으로 예비비·VAT를 원단위 반올림합니다. 기본 단가는 시세 검증 없이 유지하며 출처·기준일을 기록합니다.
- 내역서 시트 선택, 원단위 반올림/버림, 행번호·차액·검토사유, 구성단가 합계, 음수/누락/중복 가능 항목, 합계/소계 중복 합산 방지를 지원합니다. 누락 금액이 있으면 불완전 합계를 표시합니다. 수식은 캐시값을 사용하며 Excel 재계산을 대신하지 않습니다.
- SVG/PDF가 같은 그래픽을 사용해 범례·격자·가정 치수·축척막대·모듈 명세를 일치시킵니다. 가정 좌표 기준 그림으로 실측 축척/인허가 도면이 아닙니다.
- 이전 프로젝트는 새 면적/금액 기준으로 재계산하므로 이전 총액과 비교하세요. 면적 기준 선택이 없는 구버전은 수평면적·%·토공비 포함으로 불러옵니다.
- 검증: npm test. PDF 샘플: npm install 후 npm run test:report (개발용 @napi-rs/canvas 필요).
