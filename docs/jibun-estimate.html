🗺️ 지번 기반 개략공사비 산출 (프로토타입)

면적·설계 가정을 입력하면 토목/전기/태양광 공종별 개략공사비를 자동 계산합니다. 모든 계산은 브라우저에서만 이루어집니다.

1. 부지 정보

브이월드 API 키 설정 (좌표 조회에만 사용, 현재 화면에서만 사용)

무료 발급: www.vworld.kr → 오픈API 신청. 용도지역·지목 자동조회는 추가 연동이 필요해 이번 버전은 좌표만 참고용으로 제공합니다. 정확한 면적·용도지역은 아래에 직접 입력해주세요.

사면적 = 수평면적 × √(1+(경사율/100)²). 입력이 이미 수평면적이면 설치 면적에 경사계수를 다시 곱하지 않습니다. 평균 경사의 단일 평면 근사이며 경사 방향별 음영은 미반영입니다.

토공량 = 수평면적 × 평균 수직 두께의 개략 취급량. 절토/성토, 토질·운반거리·팽창/다짐계수는 별도 검토하세요. 별도 산정 시 부지조성 단가에 포함된 토공비를 제외해야 합니다.

현재는 수동 입력 기반입니다. 1:1000 지형도·필지경계·DEM 분석은 연결되지 않았습니다. 경사도만으로 토공량을 확정할 수 없어 평균 깊이를 별도로 입력합니다. 기본 단가는 검증된 시세가 아닌 편집 가능한 예시입니다.

모듈 방향 · 태양 조건

계절별 일사량 입력 · 발전량 계산 (선택)

선택한 경사각·방위각의 모듈 면 일사량(POA, kWh/㎡/일)을 입력하세요. 수평면 일사량(GHI)은 그대로 사용할 수 없습니다. 기상자료 자동조회는 미연동이며 빈 값은 추정하지 않습니다.

배치도는 위쪽이 진북이며 기본값은 정남향입니다. 행 방향은 동서, 행 간격은 남북으로 계산합니다. 태양시는 한국 표준시와 다릅니다. 위도는 좌표 조회 성공 시 자동 반영됩니다.

현장사진 · 드론사진 · 프로젝트 보관

사진과 현장 검토 메모를 배치도 PDF에 함께 첨부합니다. 사진에서 실제 경계·높이·토공량을 자동 측정하지 않습니다. 측량 성과·정사영상·표고 자료로 별도 검증하세요.

사진은 기기에서 최대 1600px로 줄여 처리하며 서버로 업로드하지 않습니다. EXIF 촬영정보는 보존되지 않으므로 원본을 별도 보관하고 촬영일·방향을 메모에 적어주세요. 새로고침 전 프로젝트 파일로 저장하세요.

계절별 태양 조건

평탄한 부지·동일한 설치 높이·동일 경사각·평행 행을 가정한 기하 계산입니다. 지형 경사·수목·건물·수평선 음영, 산란광과 부분 음영의 전기적 손실은 별도 검토가 필요합니다. 남중 직달 입사계수와 낮 길이는 실제 일사량이나 발전량이 아닙니다.

이 결과는 면적 환산·배치·사용자 단가 기반의 개략 추정치이며, 실시설계·정밀 물량산출을 대체하지 않습니다. 실제 발주·계약 전 반드시 상세 내역서 검토가 필요합니다.
